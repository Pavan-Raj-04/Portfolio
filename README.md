# 🧑‍💻 Pavan Raj A R — Personal Portfolio

A clean, multi-page personal portfolio website built with pure **HTML** and **CSS** — no frameworks, no libraries.

---

## 🌐 Live Pages

| Page | Description |
|------|-------------|
| `index.html` | Home / Hero section |
| `resume.html` | Education, Skills & Interests |
| `projects.html` | Project showcases |
| `contact.html` | Contact form & details |

---

## ✨ Features

- Responsive navigation bar across all pages
- Circular profile picture with CSS background
- Animated hover effects on nav links and buttons
- Resume section with education, skills, tools & languages
- Project showcase with images and descriptions
- Contact form with name, email, subject and message fields
- Footer with phone, email, LinkedIn and location on every page

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```

2. **Open in browser**
   ```bash
   cd portfolio
   open index.html
   ```
   Or just double-click `index.html` — no server needed!
